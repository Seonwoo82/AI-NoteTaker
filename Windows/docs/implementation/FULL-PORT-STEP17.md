# 녹음 음량과 목소리 등록 입력 표시

2026-09-16. upstream `2aaf0532e48016b32571c7929984a8f474e812ee`를 다시 fetch하고 현재 Windows 브랜치에 포함되어 있음을 확인했다. Apple의 `NoteTaker/Settings/AppSettings.swift`, `SettingsView.swift`와 목소리 등록 1.4.1 요구사항을 대조해 남아 있던 개별 음량 조절과 입력 감지 시간 표시를 추가했다.

## 녹음 설정과 적용

녹음 설정 팝오버에 마이크·시스템 소리 슬라이더를 추가했다. 0.00은 해당 소스 음소거, 1.00은 기존 기본값, 2.00은 최대 증폭이다. 0.05 간격과 키보드 명령을 지원하며 밝은/어두운 테마에 공통 슬라이더 컴포넌트를 사용한다. 녹음 중에는 변경할 수 없고 단일 소스 모드에서는 사용하지 않는 소스의 조절을 비활성화한다.

모드·장치 ID·두 음량을 `capture-settings-local.json`에 저장해 다시 실행할 때 복구한다. AI 설정/동기화 DTO와 분리하며 다른 기기의 장치 선택을 덮어쓰지 않는다. 장치 목록을 새로 읽을 때 저장된 장치가 없으면 사용 가능한 장치를 표시하지만 자동으로 저장된 선호 장치를 변경하지 않는다.

`AudioRecorder`는 시작 전에 음량을 확정하고 각 WASAPI 소스와 연결한다. 실제 저장과 라이브 분석에 사용하는 PCM 믹서에 소스별 음량을 전달한다. 기존 기본값의 평균 혼합 동작은 유지하며 증폭 결과를 16비트 범위로 제한해 정수 overflow를 방지한다. 표시용 소스 레벨에도 음량을 적용한다. UI의 현재 값은 설정 파일 저장 실패 여부와 관계없이 다음 녹음에 전달하므로 화면에서 음소거한 소스를 이전 저장값으로 녹음하지 않는다.

## 목소리 등록의 입력 감지

실제 마이크 PCM 콜백을 20ms 프레임으로 측정한다. RMS 0.0003 이상의 입력 구간만 누적하며 UI 갱신 횟수나 녹음 경과 시간으로 입력을 추정하지 않는다. 작은 입력도 확인할 수 있도록 등록 화면의 레벨 막대에는 로그 척도를 사용한다. 이 값은 주변 소리를 포함하는 입력 감지 시간이며, 말소리·본인 여부를 판별한 시간으로 표시하지 않는다. 최종 등록은 기존 Sherpa 말소리 검사를 계속 거친다.

## 검증

추가 대조에서 회의록의 생성 시각과 제공자가 보고한 비용 표시도 연결했다. 알려진 0원은 표시하고 값이 없으면 비용 문구를 생략한다. 생성 시각을 녹음 시작 시각으로 대신하지 않는다. UI fixture에서 알려지지 않은 비용의 생략과 US$ 0.0125의 표시를 확인하며 실제 유료 API 호출은 하지 않는다.

- Release 전체 테스트 **230 통과 / 장치 6 건너뜀 / 실패 0**. `Windows/artifacts/test-step17/step17.trx`. 새 검사는 음소거·개별 증폭·스테레오 보존·16비트 포화·비정상 음량 거부, 로컬 설정과 AI 설정 분리, 콜백 분할/무음/반복 조회에 따른 감지 시간 일관성을 확인한다.
- 실제 WPF 슬라이더·키보드 command·녹음 시작/완료·재시작 검사 통과. 마이크 0.5 / 시스템 1.5 설정이 저장 WAV의 좌우 PCM 값 2000 / 200에 반영되고 녹음 중 조절이 차단됐다. `ui-step17-final/capture-preferences.json`. 입력은 생성 PCM을 제공하는 fixture로 대체했으므로 실제 WASAPI 장치의 음량 측정을 주장하지 않는다.
- 실제 WPF 목소리 등록·취소·닫기·삭제·실패 보존, 공개 음성의 Sherpa 등록/실시간 추론과 Whisper/Ollama 자동 생성 경로 통과. 입력 감지 6.3초가 표시되는 것을 확인했다. `profile-step17/result.json`. 같은 화자 cosine 0.67235, 다른 화자 0.14427이며 공개 중국어 샘플 한 번 측정이다.
- 설정 팝오버의 밝은/어두운 테마와 등록 화면을 WPF로 렌더링해 확인했다. `ui-step17-final/capture-gains.png`, `capture-gains-dark.png`, `profile-step17/enrollment-light.png`. 렌더 결과이며 화면을 가리는 다른 앱과의 실제 입력 전달 검증은 아니다.

새 배포 ZIP 검사 결과는 실행 후 추가한다. 단계 16 ZIP의 10개 검사 통과는 이 변경 이전 결과다. 사용자 마이크 녹음, 주변 소리 캡처, 유료 AI, 외부 파일 전송은 실행하지 않았다.
