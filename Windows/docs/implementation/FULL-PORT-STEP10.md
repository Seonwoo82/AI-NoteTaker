# Windows 동기화 화면과 앱 작업 수명

2026-09-16. 단계 9의 전체 core 병합 실행기를 WPF 앱에 연결했다. **전체 Windows 이식은 계속 진행 중이며, 지속 웹 공유의 native 검증·긴 회의 처리·실제 회의 의미 품질·최종 포터블 배포와 PR이 남아 있다.**

## 구현

- 도구 막대의 동기화 팝오버에서 수동 실행, 중단, 진행 상태, 마지막 완료 시각, 저장된 대기 개수, 오류, 다른 기기의 클라우드 키 보유 안내를 확인한다.
- 기존 공유 서버 주소·암호화 토큰 설정을 재사용한다. 자동 동기화는 별도의 로컬 설정이며 기본값은 꺼짐이다. 기존 웹 공유 설정만 있는 라이브러리는 자동으로 업로드하지 않는다.
- 설정의 연결 확인은 실제 `v1/health`를 호출한다. 30초 제한·중단·창 닫기 취소를 지원한다. HTTPS origin만 허용하고, 자동 동기화를 켜려면 주소와 읽을 수 있는 토큰이 있어야 한다.
- 자동 동기화는 약 30초 간격이다. 실패 시 30/60/120/240/300초까지 간격이 늘며, 수동 실행과 로컬 작업 완료는 다시 확인할 기회를 만든다. 항목별 영속 재시도 시간도 계속 적용된다.
- 녹음·재생·AI 작업·설정/프로필/문서 편집·드래그/메뉴 조작 중에는 자동 시작을 미룬다. 동기화 중에는 편집을 잠그며, 녹음 시작과 설정 열기는 먼저 동기화를 취소하고 기다린다. 트레이에서 숨긴 상태로 계속 실행할 수 있고, 명시적 종료는 취소 완료를 기다린다.
- 해시·오디오 변환·JSON 병합은 WPF dispatcher 밖에서 실행한다. 일시정지한 플레이어와 파형 읽기를 정리한 뒤 적용하며, 부분 적용 후 취소/실패한 경우에도 설정·폴더·녹음·문서를 다시 읽는다. 같은 녹음의 오디오 버전이 바뀌면 파형과 재생 위치를 초기화한다.
- 긴 라이브러리 경로에서 Media Foundation URL sink가 `DirectoryNotFoundException`으로 실패하는 것을 재현했다. AAC 출력과 입력을 .NET 파일 스트림으로 연결하고, 낮은 샘플레이트의 모노 AAC가 최초 읽기에서 형식이 바뀌어 길이가 달라지는 문제도 보정했다. 원본은 보존한다. 구현 참고: [NAudio 2.3.0 encoder](https://github.com/naudio/NAudio/blob/v2.3.0/NAudio.Wasapi/MediaFoundationEncoder.cs), [URL reader의 모노/샘플레이트 처리](https://github.com/naudio/NAudio/blob/v2.3.0/NAudio.Wasapi/MediaFoundationReader.cs).

## 검증

- .NET 전체 테스트 **198 통과 / 하드웨어 5 건너뜀 / 실패 0**. 자동 실행 시계의 busy/disabled, 30초 주기, 재시도 상한/리셋을 검증했다. 긴 한글 경로 및 16kHz 모노 AAC 왕복 테스트는 수정 전 실패를 재현하고 수정 후 통과했으며 원본 바이트와 길이를 확인했다.
- WPF 빌드 경고 0 / 오류 0.
- 실제 WPF 실행 `--smoke-sync`와 실제 Worker HTTP/SQLite 왕복 결과: `Windows/artifacts/sync-step10-ui-final/result.json`.
- 독립 WPF 라이브러리 2개에서 녹음·회의록 원문·폴더·프로필·AI 설정이 반영되는 것, 자동 동기화 opt-in, 수동/자동 실행, 모달 편집 중 지연, 오프라인 실패 후 앱 재시작/재전송, 연결 확인, 잘못된 서버 경로 거부, 일시정지한 파일 reader 해제 후 새 오디오 버전 반영을 확인했다.
- 네트워크 응답 대기 중 설정 열기/녹음 시작/명시적 종료는 먼저 취소가 완료되는 것을 확인했다. 입력은 합성 WAV를 기록하는 `IRecordingSession`으로, 실제 사용자 마이크를 열지 않았다.
- 팝오버 밝은/어두운 화면, 설정의 동기화 카드로 이동, 840×600 창을 PNG로 렌더하고 확인했다. 최초 설정 이동에서 카드 아래쪽만 보이던 스크롤도 수정했다.
- 최종 소스로 기존 `--smoke-ui` 회귀도 통과했다. 결과와 렌더는 `Windows/artifacts/sync-step10-regression/`에 있다.

위 네트워크 검증은 실제 Worker와 SQLite를 사용하되 R2는 파일 시스템 대체 구현이며, 오프라인/응답 지연은 HTTP handler에서 주입했다. 실제 배포된 Cloudflare, Apple 실기기, 실제 마이크 및 출력 장치의 청취/장시간 동작을 검증한 것으로 주장하지 않는다. 물리 입력·실제 회의의 의미/화자 정확도는 별도 검증 범위로 남는다.
