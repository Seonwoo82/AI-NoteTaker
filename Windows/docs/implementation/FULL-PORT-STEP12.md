# 자연 대화 검증과 전체 화자 연결 보완

2026-09-16. 단계 11의 긴 녹음 구현을 자연 한국어 대화로 평가했다. 0.4.0 패키지는 별도 새 폴더 검증을 진행한다. 이 문서의 수치는 전체 제품 정확도 보장이 아니다.

## 공개 음성과 평가 범위

Nexdata가 공개한 [한국어 대화 평가 샘플](https://huggingface.co/datasets/Nexdata-AI/200-Hours-Korean-Full-Duplex-Multi-Channel-Speech-Data-Sample)의 `00002_003_O1_phone.wav`를 사용했다. revision `d43ff7a1bba436e9083ffc1cb98477864f701e3f`, 실제 WAV 24kHz/16bit/mono, 1,244.80초다. 함께 공개한 정답은 O1 한 사람의 129개 구간, 총 417.37초만 포함한다. 업무 회의가 아닌 자연 대화이며 다른 사람과 전체 시간의 정답이 없어 화자 오류율(DER)이나 전체 녹음의 문자 오류율을 산출하지 않았다. 원본 음성·정답·생성 내용은 ignored artifacts에만 보관하고 저장소나 배포 ZIP에 포함하지 않는다.

전사 입력에는 정답을 제공하지 않았다. 기본 Whisper large-v3-turbo/CUDA12가 11개 구간을 **29.51초**에 전사했다. RTX 4070 Ti 개발 PC의 한 번 측정이며 다른 PC 성능을 뜻하지 않는다. 참조가 있는 구간에서 예측 단어 시간의 중간값을 기준으로 문자를 모아 비교했다. 공백·구두점·주석 표기를 제외하고 숫자 표현은 치환하지 않았다. 참조 1,982자에 편집 770개, 구간별 CER 합산은 **38.85%**다. 발화 누락·단어 인식·시간 정렬 오류가 섞인 수치로, 높은 정확도를 입증하는 결과가 아니다.

재현 도구: `Windows/evaluation/score-timed-transcript.py <ASR result.json> <labels.txt> <output.json>`. 자료와 결과는 `Windows/artifacts/korean-dialogue/`에 있다. 짧은 합성 문장의 이전 결과로 자연 대화 품질을 대신하지 않는다.

## 발견과 수정

5분 구간별 음성 특징을 강하게 일치하는 경우에만 연결하던 자동 경로가 같은 목소리의 변화를 여러 그룹으로 남겼다. 이 샘플에서 자동 후보 19개가 생겼다. 인원 지정 때만 수행하던 전체 병합을 자동 경로에도 적용했다. 최종 병합은 complete linkage로 모든 후보 쌍의 유사도 하한을 확인하므로 중간에 비슷한 목소리가 있다는 이유만으로 서로 다른 두 목소리를 연쇄 합치지 않는다. 동시에 말한 후보는 합치지 않는다. [Sherpa의 complete-link cosine clustering 참고](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/sherpa-onnx/csrc/fast-clustering.cc)

구간을 요약한 임베딩에는 native 프레임별 거리 상한과 별도의 보수적인 cosine 하한 0.5를 사용한다. 이는 완벽한 화자 판별 임계값이 아니다. 변경 후 같은 파일은 **88.62초에 7개 음향 후보/144개 구간**으로 처리됐고 취소가 정상 작동했다. 후보 수가 실제 참여자 수와 일치한다는 뜻은 아니다. 상세 전사와 결합한 결과는 400개 발화, 표시된 그룹 4개, 미확인 발화 214개였다. 불명확한 구간을 임의의 사람에게 배정하지 않았다.

- 서로 다른 구간의 약한 반복 일치, 중간 목소리를 통한 연쇄 오병합 방지, 높은 유사도의 동시 발화 분리를 단위 테스트로 확인했다.
- 전체 Release 테스트: **211 통과 / 장치 5 건너뜀 / 실패 0**. `Windows/artifacts/test-step12/step12.trx`.
- 6시간 fixture를 변경된 실제 worker로 다시 실행해 네 대표 화자 유지·원본 보존·취소를 확인했다. 최대 작업 집합 약 814MiB. `Windows/artifacts/long-speakers-global-step12/result.json`.

## 로컬 회의록과 의미 분석

동일한 실제 전사와 화자 결과를 `conversation` 평가 명령으로 Qwen3.5 4B에 전달했다. 외부 정답은 전달하지 않았다. 회의록 108.40초, 구조화 분석 94.94초/21회 호출로 종료했다. 전사 정리는 모델 출력 미완료로 실패했지만 원문으로 회의록을 만들고 실패 사유를 남겼다. 원본 음성·전사 파일은 변경되지 않았다. 결과: `Windows/artifacts/korean-dialogue/meeting-qwen4b/`.

분석은 업무 1개, 질문 9개, 결정 0개를 생성했다. 직접 확인한 결과 자기소개를 미답변 질문으로 분류한 오류가 있었다. 요약에도 전사의 오인식과 일부 해석이 이어졌다. 구조 검증과 실제 근거 ID 연결은 의미의 정확성을 보장하지 않는다. 사용자는 원문·발화 구간과 대조해야 하며 실제 업무 회의의 정답 기반 품질과 더 큰 모델 비교는 남아 있다.

음성 입력·전사·화자 연결·회의록·분석의 연속 처리를 실제 파일로 검증했지만 사용자 마이크, 출력 장치 청취, 실제 Apple 기기 또는 Cloudflare 배포를 확인한 것은 아니다.
