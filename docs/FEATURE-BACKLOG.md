## 이번 릴리스에 포함되는 기능

### F-001 · 회의록 전사문 발화자 구분

상태: 구현 및 검증 완료

- [x] 전사문을 발화 구간별로 나누고 서로 다른 발화자를 구분한다.
- [x] 화자 라벨, 시간, 소유자 추정 상태를 화면에 표시한다.
- [x] 전사문에서 발화자 정보와 해당 녹음 구간 재생을 함께 제공한다.
- [x] 긴 회의에서도 화면이 한 번에 모든 발화를 eager-render 하지 않도록 목록 렌더링을 제한한다.

사용자 요청: “회의록 전사문 발화자별 구분”

### F-002 · 내 목소리 프로필과 녹음 중 본인 발화 표시

상태: 구현 및 검증 완료

- [x] 설정에 **프로필** 영역을 추가한다.
- [x] 사용자가 자신의 목소리를 등록·재등록·삭제할 수 있게 한다.
- [x] 등록 음성과 화자 임베딩을 비교해 앱 소유주의 발화 가능성을 표시한다.
- [x] 본인으로 추정된 구간에는 **나** 표시와 강조 UI를 제공한다.
- [x] 판단이 불확실한 구간은 확정된 본인 발화와 구분하여 표시한다.
- [x] 목소리 프로필은 기기 로컬에만 보관하고 Cloudflare 동기화에서 제외한다.

사용자 요청: “설정 > 프로필 탭 신설해서 내 목소리 녹음해두면 녹음 중 발화자가 앱 소유주인 경우를 탐지하여 나라는 것을 확인하기 좋도록 ui 효과 추가하기”

주의: 이 기능은 편의용 화자 표시입니다. 계정 인증, 법적 신원 확인, 완벽한 생체 판별을 보장하지 않습니다.

### F-003 · 내 발화만 모아 보기 및 원본 발화 구간 연속 재생

상태: 구현 및 검증 완료

- [x] 내 발화로 추정되거나 사용자가 본인으로 지정한 발화를 모아 보여준다.
- [x] 내 발화 구간을 원본 녹음에서 연속 재생한다.
- [x] 녹음·목소리 등록 등 오디오 세션이 바쁜 상태에서는 근거 재생을 막는다.

### F-004 · 내가 한 약속과 나에게 요청된 업무 분류

상태: 구현 및 검증 완료

- [x] AI가 약속과 요청을 구분하고 발화 근거를 연결한다.
- [x] 항목별 `open`, `done`, `dismissed` 상태를 관리한다.
- [x] 수동 상태 변경을 동기화 가능한 수정 이력으로 보관한다.

### F-005 · 질문과 답변 연결

상태: 구현 및 검증 완료

- [x] 질문과 답변을 연결한다.
- [x] 답변이 없거나 불확실한 질문을 따로 보여준다.
- [x] 각 질문과 답변에서 원본 발화 근거로 이동할 수 있게 한다.

### F-006 · 결정 흐름과 원본 발화 근거 표시

상태: 구현 및 검증 완료

- [x] 제안·우려·보류·수정·결정 단계를 시간 흐름으로 정리한다.
- [x] 각 단계가 실제 전사 발화 ID를 근거로 갖도록 검증한다.
- [x] 근거 발화 재생과 회의 분석 탭 이동을 지원한다.

### F-007 · 프로젝트별 이전 회의 브리핑

상태: 구현 및 검증 완료

- [x] 회의에 프로젝트 이름을 지정한다.
- [x] 같은 프로젝트의 이전 회의에서 결정, 열린 약속, 미해결 질문을 모은다.
- [x] 브리핑 항목에서 원본 회의와 근거 발화로 이동한다.
- [x] 프로젝트가 하나뿐인 경우 빈 선택 화면 대신 자동 선택한다.

### F-008 · 이름·별칭·역할 프로필과 용어 사전

상태: 구현 및 검증 완료

- [x] 표시 이름, 별칭, 역할을 저장한다.
- [x] 사람·회사·프로젝트·약어·일반 용어 사전을 저장한다.
- [x] 프로필과 용어 사전을 OpenRouter 분석 프롬프트 컨텍스트로 전달한다.
- [x] 전사문 표시에서 “들린 표현 → 선호 표기” 주석을 제공하되 원본 전사는 보존한다.
- [x] 텍스트 프로필은 Cloudflare에 동기화하고, API 키와 목소리 프로필은 제외한다.

### F-009 · 화자 이름 및 본인 표시 수정

상태: 구현 및 검증 완료

- [x] 화자 이름을 수정한다.
- [x] 화자를 앱 소유자로 표시하거나 해제한다.
- [x] 개별 발화의 화자를 재지정한다.
- [x] 수정 이력은 재분석과 동기화 이후에도 적용될 수 있도록 별도 문서로 저장한다.

### F-010 · 텍스트 프로필·분석 결과·수정 사항 자동 동기화

상태: 구현 및 검증 완료

- [x] 텍스트 프로필, 추가 분석 opt-in, 회의 분석 문서, 수정 이력을 Cloudflare Worker/D1/R2에 동기화한다.
- [x] OpenRouter API 키, Cloudflare 동기화 키, 목소리 등록 데이터, 화자 임베딩을 동기화하지 않는다.
- [x] 한 기기에만 OpenRouter 키가 있을 때 다른 기기에서 안내 메시지와 입력 유도를 제공한다.
- [x] 오프라인 변경과 재시작 후 재시도를 보존한다.

## 명시적으로 제외한 범위

- Mac과 iPhone을 같은 라이브 회의로 묶어 동시에 녹음한 오디오를 자동 병합하는 기능.
- 동시 녹음의 타임라인 정렬, 중복 음성 제거, 다중 장치 마이크 퓨전.
- 목소리 프로필 또는 화자 추정을 인증 수단으로 사용하는 기능.
- API 키, 동기화 키, 목소리 샘플, 화자 임베딩의 Cloudflare 업로드.

## 다음에 추가하면 좋은 후보

- 전사문 검색과 화자·프로젝트·업무 상태 필터.
- 화자 병합/분리 UI와 “이 화자는 같은 사람” correction flow.
- 회의별 액션 항목을 전체 라이브러리에서 모아 보는 업무 대시보드.
- 캘린더 일정 제목·참석자 기반 프로젝트 추천.
- 브리핑을 Markdown, PDF, Clipboard용 요약 형식으로 내보내기.
- 모델 준비 상태, 다운로드 용량, 오프라인 모델 경로를 보여주는 진단 화면.
- 미해결 질문이나 열린 약속을 다음 녹음 시작 전 알림으로 보여주는 기능.
- 긴 회의에서 자동 챕터, 침묵 구간 건너뛰기, 재생 속도 조절.
