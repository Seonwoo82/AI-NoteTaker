# Mac·iPhone 무료 로컬 AI

AI 설정에서 **무료 · 이 기기**를 선택하면 Apple의 온디바이스 음성 인식으로 전사문을 만들고, Apple Intelligence 모델로 회의록을 생성합니다. API 키와 AI 호출 요금이 필요하지 않습니다.

| 작업 | 사용 모델·기능 |
| --- | --- |
| 음성 전사 | Apple Speech, 선택한 언어의 온디바이스 인식 |
| 회의록 생성 | Apple Intelligence의 FoundationModels 시스템 모델 |
| 클라우드 처리 선택 | 기존 OpenRouter 키·모델 설정 |

## 지원 조건

- Mac: Apple Silicon, macOS 26 이상, Apple Intelligence 활성화 및 시스템 모델 준비 완료.
- iPhone: iOS 26 이상, iPhone 15 Pro/Pro Max 또는 iPhone 16 이후의 Apple Intelligence 지원 모델. Apple Intelligence 활성화와 모델 준비가 필요합니다.
- 선택한 전사 언어의 온디바이스 음성 인식이 해당 기기에서 지원되어야 합니다. 한국어와 영어를 선택할 수 있습니다.
- 음성 인식 권한을 허용해야 합니다. 모델 준비와 최초 시스템 설정에는 인터넷이 필요할 수 있습니다.

앱이 실제 모델 상태와 언어 지원 여부를 확인해 사용 가능 여부를 표시합니다. 지원되지 않는 기기·OS에서는 이유를 안내합니다. 기존 iOS 17 이상 앱 지원 범위와 OpenRouter 기능은 유지됩니다.

공식 요구 사항: [Apple Intelligence 지원 기기·언어](https://support.apple.com/ko-kr/121115), [FoundationModels 언어 지원 확인](https://developer.apple.com/documentation/foundationmodels/supporting-languages-and-locales-with-foundation-models).

## 사용 방법

1. AI 설정에서 **무료 · 이 기기**를 선택합니다.
2. 녹음한 내용의 언어를 한국어 또는 영어로 선택합니다.
3. 로컬 AI 준비·확인을 누르고 음성 인식 권한을 허용합니다.
4. Apple Intelligence가 꺼져 있거나 모델이 준비 중이면 시스템 설정에서 준비를 마친 뒤 다시 확인합니다.
5. 녹음을 선택해 회의록을 생성합니다. 자동 생성 설정을 켜면 새 녹음에도 적용됩니다.

로컬 모드는 각 기기에서 선택합니다. 기존 OpenRouter 키와 모델은 지우지 않으므로 모드를 바꾸면 다시 사용할 수 있습니다.

## 처리와 데이터

로컬 모드에서는 음성 인식의 서버 처리를 허용하지 않으며, 모델을 사용할 수 없거나 생성에 실패해도 OpenRouter로 자동 전환하지 않습니다. AI 처리는 기기 안에서 이루어집니다. 기기 간 동기화와 웹 공유는 각 설정에 따라 별도로 동작합니다.

긴 음성은 짧은 구간으로 전사하고, 긴 전사문은 구간별 요약을 거쳐 회의록으로 합칩니다. 시스템 모델의 문맥 길이와 앱의 처리 상한을 넘으면 오류를 안내하며 기존 회의록을 유지합니다. 작은 기기에서는 처리 시간이 길어지거나 발열·배터리 소모가 늘 수 있습니다.

현재 무료 모드의 범위는 전사와 회의록 생성입니다. OpenRouter 기반 참여자 구분, 구조화된 회의 분석, AI 보완 및 전사 정리는 OpenRouter 모드에서 사용할 수 있습니다. 기존 분석 결과를 읽는 기능과 완성된 회의록의 웹 공유는 계속 사용할 수 있습니다.

## 개발 구조

`Shared/LocalAI/`에 공통 모델 식별자, 지원 상태 확인, 로컬 엔진과 공급자 분기를 둡니다. Mac·iPhone은 같은 로컬 엔진을 사용하며, 각 앱의 AI 설정과 회의록 생성 흐름에서 선택한 모드를 적용합니다. 외부 패키지를 추가하지 않습니다.

모델을 실행하는 실제 기기 검증과, 모델·권한 상태를 주입하는 자동 테스트를 구분합니다. iPhone 시뮬레이터의 음성 모델 지원은 실제 기기와 다를 수 있습니다.

## 2026-09-15 검증 결과

| 검증 | 결과 |
| --- | --- |
| Mac 앱 빌드·테스트 | 83개 통과, 0개 실패, 실제 모델 실행 테스트 1개 명시적으로 제외 |
| iPhone 시뮬레이터 앱 빌드·테스트 | 88개 통과, 0개 실패, 실제 모델 실행 테스트 1개 명시적으로 제외 |
| 실제 Apple Intelligence 요약 | 이 Mac에서 운영 코드 `AppleOnDeviceAIClient.complete`를 연결한 별도 실행으로 테스트용 한국어 회의 요약 생성, 비용 값 0, 완료 표식 제거 확인 |
| 설정 화면 | Mac·iPhone 화면 확인, 로컬 설정 진입 시 클라우드 모델 조회 없음 |
| 이전 기능 | OpenRouter 설정·동기화·기존 회의록 생성, 클라우드 분석 경로 회귀 테스트 포함 |

자동 테스트에는 로컬 실패 시 클라우드 미호출, 취소와 중복 콜백, API 키 없는 생성, 클라우드 전사문 재사용 방지, 비용 0, 준비 중 언어 변경, 로컬 모드에서 클라우드 분석 차단을 포함합니다. 실제 요약 확인에는 개인 녹음이나 전사문을 사용하지 않았습니다.

이 기능을 포함한 Mac 1.7.0(빌드 19)을 로컬에 서명·설치했습니다. [설치 및 전체 회귀 검증 기록](implementation/SPEAKER-OWNER-REPAIR.md)

**검증하지 않은 범위:** 실제 음성 파일을 Apple Speech로 전사하는 권한 허용 후 전체 흐름, 실물 iPhone의 모델 실행, 장시간 녹음의 정확도·성능. 이 Mac의 한국어 온디바이스 음성 지원 상태는 확인했지만 테스트를 위해 음성 인식 권한을 새로 요청하지는 않았습니다.
