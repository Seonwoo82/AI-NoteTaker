# 참여자 요청 호환성과 녹음 폴더

## 작업 계획

- [x] 참여자 구분의 실패를 기존 회의록 생성 상태와 분리하고 원본 문서를 유지한다.
- [x] 타임스탬프를 지원하지 않는 GPT Transcribe 계열은 참여자 구분에서만 호환 Whisper 모델을 사용한다. 실제 사용한 전사 모델과 캐시 출처를 기록한다.
- [x] 요청 형식 400 오류는 참여자 작업에 한정해 안내하며 무한 재시도하지 않는다.
- [x] 사용자 폴더 생성·이름 변경·녹음 이동·폴더 삭제를 Mac/iPhone 목록에 제공한다.
- [x] 폴더는 UUID 기반 독립 메타데이터로 빈 폴더도 보존한다. 삭제는 폴더만 없애고 녹음은 전체 목록에 유지한다.
- [x] 폴더별 변경 순서와 삭제 상태, 녹음의 폴더 연결을 Cloudflare로 동기화한다. 이전 앱이 생략한 필드가 현재 폴더 연결을 지우지 않게 한다.

새 의존성이나 사용자 녹음의 테스트 업로드는 추가하지 않는다. Xcode 검증은 루트에서 `-jobs 2`로 순차 실행한다.

## 근거

사용자가 참여자 구분에서 OpenRouter 400을 확인했다. 앱은 모든 모델에 `verbose_json`과 단어/구간 타임스탬프를 요청하고 있었다. OpenRouter 문서는 이 형식을 지원하지 않는 제공자·모델이 400으로 거절한다고 명시한다.

- [OpenRouter 타임스탬프 전사 문서](https://openrouter.ai/docs/guides/overview/multimodal/stt)
- [GPT Transcribe 모델 정보](https://openrouter.ai/openai/gpt-transcribe)

## 실제 동작과 회귀 검증

- 기본 GPT 전사와 회의록의 모델·텍스트를 유지하고, 참여자 전사의 실제 Whisper 출처를 별도 필드로 저장한다. 명시적인 참여자 구분 작업이 실패해도 기존 회의록 상태는 완료로 유지된다.
- 타임스탬프 오류 또는 400은 첫 구간에서만 한 번 대체한다. 401 등 인증 오류나 이미 Whisper인 요청은 반복하지 않는다. 설정 자체를 바꾸지 않는다.
- 폴더 생성·이름 변경·이동·삭제와 빈 폴더 동기화를 지원한다. 폴더 삭제는 오디오를 지우지 않는다. 녹음 시작 때의 폴더를 캡처하여 녹음 도중 목록 이동의 영향을 받지 않는다.
- 로컬 폴더 파일은 512 KiB로 제한하고 원자적으로 저장한다. 손상된 기존 파일을 기본값으로 덮어쓰지 않는다. 오래된 앱의 생략 필드와 명시적 폴더 해제를 구분한다.
- 기존 오류 처리로 되돌린 회귀 테스트에서 400이 `.failed`로 표시되는 실패를 확인한 뒤 수정 구현을 복구했다.
- Mac 419개, iOS 293개, Worker 55개 테스트 통과. Mac·iPhone 한국어 폴더 화면을 독립 테스트 저장소로 정적 렌더하여 확인했다.
- 실제 개인 녹음의 OpenRouter 유료 재요청, 마이크 녹음, 실제 두 기기의 폴더 편집은 자동으로 실행하지 않았다. 실제 제공자 응답과 개인 회의의 화자 인식 품질은 사용자 재시도로 확인해야 한다.
