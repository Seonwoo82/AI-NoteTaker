# 맥락 기반 전사 정리 — 1.6.0 (빌드 17)

## 동작

새 회의록은 음성 인식 이후 선택한 회의록 모델로 전사를 먼저 정리한다. 모델에는 앞뒤 대화, 도입부, 기존 참여자 정보와 시간을 참고 자료로 제공한다. 명확한 비음성 표기·잡음성 문구·반복 오인식을 정리하며, 짧은 답변·주제 전환·반대 의견·낯선 이름을 단지 어색하다는 이유로 없애지 않도록 지시한다.

원본 녹음과 전사, 참여자 ID와 시간은 보관한다. 전사 화면에서 **AI 정리본 / 원문**을 비교하고, 정리에 사용한 모델과 제외된 구간 수를 확인할 수 있다. 기존 회의록의 **전사 정리**는 오디오를 다시 전사하지 않고 정리본만 추가한다. 기존 Markdown 회의록은 유지한다. **다시 생성**은 정리본을 바탕으로 회의록도 다시 작성한다.

**설정 → AI 회의록 → 맥락 기반 전사 정리**가 기본으로 켜진다. 선택한 회의록 모델을 사용하므로 추가 모델 사용료가 생길 수 있다. 자동 정리를 끄더라도 기존 전사에 대한 수동 정리는 가능하다. 이 설정과 정리본은 연결된 기기에 동기화한다.

## 보존과 검증

- 모델에는 원문 구간 ID를 전달하며 응답이 모든 ID를 정확히 포함해야 한다. 응답 순서가 달라도 ID로 원래 순서를 복원한다.
- 남겨 둔 문장의 숫자·시간 표기는 값뿐 아니라 등장 횟수와 순서도 검사한다. 인명·부정·일정·제안과 확정의 차이를 보존하도록 지시한다.
- 길이와 무관하게 원문의 비공백 문자 중 절반 미만만 남거나 모든 내용이 사라지면 정리를 거부하고 원문을 사용한다.
- 정리 실패가 기본 회의록 생성을 중단하지 않게 하고, 이유를 안내한다. 수동 정리의 취소·실패·다른 기기 갱신은 기존 문서를 덮어쓰지 않는다.
- 원문 해시가 같은 정리본은 일반 재생성 때 재사용한다. 수동 **전사 다시 정리**는 새 정리를 요청한다.
- 정리본이 전체 문서 2 MiB 저장 한도를 넘으면 기본 회의록 생성에서는 정리본을 제외하고 원문과 회의록을 보관한다.

기계적 검증이 의미 보존을 완전히 증명하지는 못한다. AI가 판단한 결과는 원문과 대조할 수 있게 제공한다. 실제 녹음의 음향적 잡음과 화자 인식 정확도 자체를 바꾸는 모델은 추가하지 않았다.

## 저장·동기화

`MeetingNotesDocument.transcriptCleanup`은 선택적 데이터다. `schemaVersion`, `modelID`, `sourceKind`, `sourceHash`, `passages`를 저장한다. 각 passage는 기존 구간의 `id`와 정리한 `text`만 갖는다. 빈 텍스트는 제외한 구간을 뜻한다. 참여자의 ID·이름·시간을 모델이 바꾸는 필드는 없다.

- 일반 전사: 빈 문단을 제외하고 문단별 2,000 Unicode scalar 단위로 나누어 `p0`, `p1` 순서로 식별한다. 원문 전체의 해시를 검사한다.
- 참여자 전사: 기존 발화 ID와 텍스트를 길이 접두사로 연결한 해시를 검사한다.
- Worker는 원문 해시, 순서·ID·필드·길이를 검증한다. 기존 앱이 정리 설정을 생략해도 서버의 값을 보존한다. DB 마이그레이션은 필요하지 않다.

공유 `TranscriptCleanup.swift`에서 구간 구성·검증·모델 요청을 재사용하고, 양쪽 `MeetingNotesService`/`MeetingNotesView`와 기존 동기화 경로에 연결했다. 새 의존성은 없다.

## 검증 기록

- 기존 프롬프트의 맥락별 잡음 처리 누락을 확인한 뒤 정책과 전사 정리 단계를 추가했다.
- 자동 정리→회의록 입력, 수동 정리의 STT 재호출 방지, 원문 유지, 비활성화, 오류 복구, 취소·동기화 충돌, 요청 크기와 구간 순서 등을 검증한다.
- 리뷰에서 짧은 전사의 과도 삭제와 반복 숫자/시간 삭제가 허용되는 사례를 재현한 뒤 수정했다.
- 실제 사용자 녹음을 대상으로 유료 정리 요청은 실행하지 않았다. 모델 응답은 테스트 대역으로 검증하며, 한국어 Mac·iPhone 화면은 별도 테스트 라이브러리로 렌더했다.
- 최종 검증: Mac 463개, iOS 332개, Worker 60개 테스트 통과. 두 플랫폼 Release 빌드와 코드서명 검증 완료.
- Mac 1.6.0 (17)은 기존 앱·라이브러리를 백업하고 설치했다. 기존 회의록 파일 해시 보존, 실행 파일 일치, 실행 상태를 확인했다. 실제 앱의 전사 정리 버튼·개인정보 없는 보완 예시도 확인했다.
- Worker `5accd5e0-7557-42a0-ac7f-83f673179d6f` 배포 완료. 인증된 health/notes/AI 설정 조회가 HTTP 200을 반환했다.
- iPhone용 Release와 로컬 IPA를 준비했으나 기기 연결 불가로 설치하지 못했다. 기존 기기 설치본은 유지한다.
