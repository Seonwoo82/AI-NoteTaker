# iPhone 녹음 바 레이아웃 — iOS 1.6.1 (빌드 18)

## 원인과 수정

녹음 시간, 내 목소리 상태, 일시정지, 완료 버튼이 하나의 가로 줄에서 공간을 나누면서 작은 화면에서는 글자가 잘리거나 세로로 줄바꿈되었다. 저장 대기 상태는 큰 글자 설정에서 화면 너비도 초과했다.

- 위에는 녹음 상태와 시간, 내 목소리 상태를 배치하고 아래에는 조작 버튼을 배치한다.
- 일시정지·재개와 완료 버튼은 최소 50pt 높이로 넓게 표시한다. 버튼 제목은 한 줄을 유지한다.
- 가로 공간이 부족하면 상태 영역과 조작 버튼을 각각 세로 배치로 전환한다. 접근성 글자 크기를 강제로 줄이지 않는다.
- 일시정지 중에는 오래된 내 목소리 상태를 표시하지 않는다. 저장 중에는 진행 표시와 상태 문구를 보여 주고 조작을 비활성화한다.
- 저장 대기의 나중에 저장·재시도 버튼에도 같은 적응형 배치를 적용한다.

`iOS/NoteTaker/Views/RecordingBar.swift`에서 기존 녹음 상태와 동작을 그대로 사용한다. 녹음·저장·동기화 로직이나 Mac 앱은 변경하지 않는다. 새 의존성은 없다.

## 검증

`RecordingBarLayoutTests`는 임시 라이브러리와 가짜 오디오 백엔드만 사용한다. 마이크 접근, 실제 녹음 시작, 운영 데이터 변경 없이 화면을 렌더한다.

- 변경 전 저장 대기·접근성 크기에서 너비 제한 테스트 실패를 확인했다.
- 320pt / 393pt, 한 시간 이상의 시간 표시, 녹음·일시정지·저장·저장 대기, 기본 및 최대 접근성 글자 크기를 확인한다.
- 전체 라이브러리 화면의 하단 영역에 녹음 바가 배치되는 모습도 확인한다.
- 실제 마이크 녹음은 자동 실행하지 않는다.

## 완료 기록

- 기존 iOS Swift Testing 332개 및 녹음 바 XCTest 3개를 포함한 전체 테스트 통과.
- 10개 녹음 바/라이브러리 화면을 렌더하여 확인했다. 최대 접근성 크기의 좁은 화면에서 아이콘까지 들어가지 않으면 글자 크기를 줄이지 않고 제목을 우선 표시한다.
- iOS 1.6.1 (18) Release 빌드·코드서명·개발용 로컬 IPA 검증 완료. 실제 iPhone 설치 버전 조회와 실행 성공 확인.
- 사용자 녹음을 자동으로 시작하지 않았으므로 실제 녹음 중 화면은 정적 렌더로 검증했다.
