# 폴더 탐색과 드래그 이동 — 1.5.1 (빌드 15)

## 문제와 변경

폴더 생성 함수가 새 빈 폴더를 즉시 선택하면서 전체 목록이 사라진 것처럼 보였다. Mac의 전체 목록 버튼은 동작했으나 스크롤 영역 안에 있었다. iOS 필터 메뉴는 기본 필터가 여전히 `.all`인 상태에서 별도 사용자 폴더를 선택했을 때 전체 목록에 잘못 체크되어 다시 선택하기 어려웠다.

- 폴더 생성은 현재 목록·선택·재생 상태를 보존한다.
- Mac의 전체 목록·즐겨찾기·최근 삭제 항목은 상단에 고정한다. 전체 목록을 다시 눌러도 해당 목록으로 스크롤한다.
- Mac 폴더 화살표로 내부 녹음을 펼치고 접는다. 폴더 선택과 녹음 선택을 다른 강조 색으로 구분한다.
- 녹음을 폴더 헤더나 펼친 내부에 드롭하면 이동하고 대상 폴더와 녹음을 보여 준다. `여기로 끌어놓아 폴더 밖으로 이동` 영역은 폴더 연결을 해제한다.
- 폴더를 다른 폴더의 위쪽·아래쪽 절반에 놓으면 삽입선 위치로 순서를 바꾼다. 폴더 안에 폴더를 만드는 중첩 기능은 추가하지 않는다.
- iOS 필터 메뉴는 명시적 버튼으로 선택하며, 실제 사용자 폴더에 맞게 체크 표시를 한다.

## 데이터와 구현

기존 폴더 메타데이터에 선택적 `sortOrder`를 추가한다. 구버전 데이터는 이름순을 유지한다. 순서 변경은 로컬 파일에 한 번에 저장하고, 변경된 폴더만 수정 시각과 변경 ID를 갱신한다. 혼합된 구버전 데이터나 최대 순서 값 때문에 새 폴더가 중간에 들어가지 않도록 필요한 경우만 순서를 정규화한다. 폴더 삭제 기록과 녹음 파일은 유지한다.

기존 동기화 경로를 그대로 사용한다. Worker와 앱은 구버전이 순서 필드를 생략해도 기존 순서를 유지한다. 서버 DB 마이그레이션은 추가로 필요하지 않다.

Mac은 `SidebarDragItem`과 단일 드롭 처리 경로로 녹음 이동·폴더 순서를 구분한다. 실제 오디오나 전사문 대신 UUID만 전달하며, `CoreTransferable`의 `.ownProcess` 표현으로 앱 내부에 제한한다. 유효한 녹음·폴더 및 녹음 중 상태를 드롭 시 다시 검사하고, hover만으로 데이터를 변경하지 않는다. 새로운 의존성은 없다.

관련 파일: `SidebarView.swift`, `RecordingsListView.swift`, `SidebarDragItem.swift`, `SidebarDropTargetModifier.swift`, `LibraryController.swift`, 공유 `RecordingFolderStore.swift`, iOS `RootView.swift`/`LibraryAppModel.swift`, `Cloudflare/worker.mjs`와 관련 테스트.

Apple 공식 API와 설치된 macOS 26 SDK를 기준으로 구현했다: [SwiftUI drag-and-drop](https://developer.apple.com/documentation/SwiftUI/Adopting-drag-and-drop-using-SwiftUI), [식별자를 제공하는 draggable](https://developer.apple.com/documentation/swiftui/view/draggable(_:id:item:containernamespace:)).

## 검증 범위

- 변경 전 폴더 생성 회귀 테스트에서 전체 목록이 비고 사용자 폴더 선택으로 바뀌는 실패를 확인했다.
- 전체 목록 복귀, 빈 폴더 생성, 폴더 펼침·접기, 녹음 이동·폴더 해제, 유효하지 않은 드롭 거부, 파일 보존, 폴더 앞·뒤·마지막 이동을 테스트한다.
- 실제 `NSItemProvider`에 등록하여 폴더·녹음 식별자를 다시 읽고, 외부 앱으로 내보낼 표현이 없는 것을 검증한다.
- 두 테스트 라이브러리에서 폴더 순서 동기화와 이름 변경·재시작 후 순서 유지를 검증한다.
- Mac 한국어 화면은 폴더 내부, 폴더 생성 후 전체 목록, 25개 폴더가 있는 작은 창을 정적 렌더링하여 확인한다.
- 전역 마우스 입력이나 UI 테스트 러너는 사용하지 않는다. 실제 사용자 녹음에 드래그 동작을 실행하거나 임의의 운영 폴더를 만들지 않는다.
