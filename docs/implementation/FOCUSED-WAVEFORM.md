# Mac 재생 위치 주변 파형 확대

큰 파형은 녹음 전체를 보여주고, 아래의 작은 파형은 재생 위치 주변 최대 5분을 보여줍니다. 작은 파형 아래에는 구간 시작·현재 위치·구간 끝 시간이 표시됩니다.

- 일반 위치에서는 현재 시간의 앞뒤 2분 30초를 표시합니다.
- 녹음 처음과 끝에서는 5분 구간을 파일 경계 안으로 이동합니다. 54:19짜리 녹음의 52:02에서는 49:19~54:19를 표시합니다.
- 5분보다 짧은 녹음은 전체 구간을 표시합니다.
- 작은 파형을 드래그하는 동안 시간 범위를 고정합니다. 드래그를 마치거나 취소하면 현재 위치를 다시 따라갑니다. 다른 녹음이나 오디오 버전으로 바꾸면 이전 드래그 상태를 버립니다.
- 확대 파형의 접근성 조절은 1초 단위이며, 큰 파형의 기존 15초 조절은 유지합니다.

## 실제 파형 해상도

파일 전체에서 고정 96개만 추출하던 기본 파형 데이터를 약 1초당 한 값으로 늘렸습니다. 54분 파일은 3,240개의 값을 보관하고, 화면에 필요한 구간만 최대 96개 막대로 합칩니다. 작은 구간을 확대해도 실제 인접 구간의 음량 차이를 유지하기 위한 변경입니다.

기본 데이터는 최소 96개, 최대 86,400개로 제한하며 기존 16,384프레임 스트리밍 버퍼와 취소 처리를 유지합니다. 탐색할 때마다 파일을 다시 읽지 않습니다. 명시적으로 지정한 버킷 수는 기존대로 처리합니다. 원본 오디오·회의록은 수정하지 않습니다.

## 범위

이번 변경은 스크린샷에 표시된 Mac 재생 화면에 적용됩니다. iPhone과 Windows 화면은 변경하지 않았습니다.

## 검증

- 구간 계산·범위별 파형·장시간 파일 샘플링·로딩 회귀·화면 렌더링 테스트 23개 통과, 실패·제외 없음.
- 실제 마우스 드래그 테스트 통과: 한 드래그 중 재생 위치가 바뀌어도 고정된 범위로 75초 이동하고, 다음 드래그에서는 새 범위를 기준으로 75초 되돌아갑니다.
- 화면 문자 인식으로 끝 구간의 49:19 / 52:02 / 54:19와 중간 구간의 25:00 / 27:30 / 30:00을 확인했습니다.
- Mac Release 빌드·서명 검사·정적 분석 통과. Mac 1.7.2(빌드 21)을 설치했습니다.
- 설치된 앱에서 실제 54분 녹음을 열어 전체 파형으로 이동한 뒤, 확대 파형으로 52:02 부근을 조정하고 1초 접근성 이동을 확인했습니다.
