# 공유 화면과 녹음 행 클릭 영역 — 2026-09-15

## 변경

- Mac·iPhone·Windows에서 활성 링크의 새 링크 생성과 링크 열기 버튼을 제거했습니다. 최초 생성은 서버에서 비활성 상태를 확인한 경우에만 가능합니다.
- 링크 주소와 오른쪽 복사 버튼을 한 행에 배치했습니다. 둘 다 전체 URL을 복사하며, 다른 내용을 클립보드에 복사한 뒤에도 다시 누르면 링크가 복사됩니다. iPhone의 시스템 공유 아이콘도 같은 행에 있습니다.
- 공유 해제 문구를 **공유 취소**로 통일했습니다. 이 창에 주소가 없는 기존 공유도 취소할 수 있습니다. 서버의 링크 원문 저장·조회 정책은 변경하지 않았습니다.
- Mac 녹음 행의 일반 버튼 레이블 전체에 직사각형 클릭 영역을 적용했습니다. 이름 편집 중에는 해당 영역을 적용하지 않아 기존 네이티브 텍스트 필드 동작을 유지합니다. iPhone은 기존 List/NavigationLink 선택 경로를 유지합니다.
- Windows 잠금 파일에 이미 Core 프로젝트가 사용 중인 암호화 패키지의 전이 의존성을 반영해 잠금 파일 기반 복원을 확인했습니다. 새 패키지를 도입하지 않았습니다.
