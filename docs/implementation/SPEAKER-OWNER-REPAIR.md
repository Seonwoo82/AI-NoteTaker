# 화자 분리와 내 목소리 적용 수정

## 문제와 원인

두 사람이 대화한 녹음에서 짧은 발화가 별도 화자로 누적되고, 등록 목소리가 자동으로 나에게 연결되지 않는 문제가 있었습니다. 기존 분석은 독립적인 10초 구간을 순서대로 처리하며 새 화자를 만들었지만, 전체 녹음에서 같은 화자인지 다시 묶지 않았습니다. 짧거나 겹치는 발화의 불안정한 음성 특징이 추가 화자로 남을 수 있었습니다.

등록 목소리 판정 기준도 실제 대화에 비해 높았습니다. 별도 등록한 목소리와 실제 회의의 동일 인물 유사도는 약 0.76이었으나 기존 기준은 0.82였습니다. 실제 입력보다 더 조용한 녹음을 등록할 수 있으면서 실시간 판정에서는 이를 거부하고, 분석 중 새 오디오가 들어오면 결과를 계속 버리는 문제도 있었습니다.

## 수정 내용

- 기존 FluidAudio 0.15.6의 전체 녹음 분석을 사용합니다. 화자 수는 자동으로 추정하며 2명으로 제한하지 않습니다. 겹치는 발화는 유지합니다.
- 전체 분석 모델과 기존 등록 목소리 모델은 별도 캐시에 보관합니다. 내 목소리 비교용 특징은 기존 등록 모델로 다시 추출하므로 저장된 목소리 모델의 의미를 바꾸지 않습니다.
- 실제 두 사람의 독립된 구간을 비교해 판정 범위를 조정했습니다. 충분히 비슷하면 ‘나’, 충분히 다르면 ‘다른 사람’, 그 사이는 불확실하게 표시합니다. 새로운 기준은 모든 환경의 정확도를 보장하는 수치가 아닙니다.
- 조용한 발화와 짧은 쉼을 처리하고, 오디오가 계속 들어오는 동안에도 신선한 결과를 표시합니다. 오래된 결과·다른 녹음·이전 목소리 등록 결과는 적용하지 않습니다.
- 목소리 등록을 바꾸어도 화자 ID와 기존 발화 ID를 유지합니다. 발화가 없는 가짜 ‘Me’ 행은 만들지 않으며, 이전에 수동으로 지정한 ‘나’ 기록은 하나의 표시 항목으로 합칩니다.
- 저장된 회의를 열거나 목소리를 다시 등록하면 음성 특징을 기기에서 다시 적용합니다. 기존 문장·시간·회의록·결정 및 할 일·수정 기록을 보존합니다. 이 작업에 OpenRouter 호출은 필요하지 않습니다.
- 기기 내부의 `.owner-attribution.json`에 음성 특징과 적용 상태를 캐시합니다. 이 파일과 목소리 프로필은 동기화 대상에 포함되지 않습니다. 새 문서가 들어오면 이전 문서를 덮어쓰지 않도록 버전을 다시 확인합니다.

## 모델 준비

전체 녹음 분석은 `VoiceModels/offline-diarizer/speaker-diarization`에 추가 공개 모델을 내려받습니다. 기존 스트리밍 모델·등록 목소리는 보존합니다. 추가 모델이 없거나 손상되어도 기존 모델을 사용하는 실시간 목소리 인식은 유지됩니다. 다운로드가 필요한 경우 음성 모델 준비에서 진행합니다.

## 실제 녹음 검증

394.784초의 문제 녹음과 원래 목소리 프로필의 복사본으로 검증했습니다. 개인 음성이나 전사문을 외부 AI 서비스에 보내지 않았습니다.

| 항목 | 이전 | 수정 검증 |
| --- | --- | --- |
| 음향 화자 군집 | 6개 중4개에 발화 연결 | 자동 추정2개 |
| 실제 저장·표시 화자 | 추가 화자 및 중복된 ‘나’ | 저장2명, 표시2명 |
| 미지정 발화 | 32개 | 기존 발화 구분 보존 시14개 |
| 기존 수정 기록 | ‘나’가 여러 행에 분리 | 미해결 수정0개 |
| 원문·시간·회의록·원본 음성 | 기준 원본 | 동일함 확인 |
| 수정 시 클라우드 호출 | — | 0회 |

실제 음성을 0.5초 간격으로 입력한 별도 실시간 검증에서, 내 목소리10초 구간은 준비5회·나12회·불확실3회였고 상대방 구간은 준비5회·다른 사람13회·불확실2회였습니다. 상대방을 나로 판정한 경우는 없었습니다. 이는 선택한 검증 구간의 결과이며 새로운 회의나 모든 마이크 환경에 대한 보장이 아닙니다.

겹치거나 충분한 음향 근거가 없는 발화는 미지정으로 남깁니다. 인원 수를 맞추기 위해 억지로 특정 사람에게 배정하지 않습니다.

## 설치본과 회귀 검증

2026-09-15에 서명된 Mac 1.7.0(빌드 19)을 설치하고 실제 저장된 회의를 열어 확인했습니다. 발화자 화면에는 두 행만 표시되며, ‘나’는 28개 발화, 다른 사람은 41개 발화로 표시됩니다. 나머지 14개 발화는 미지정입니다. 기존 83개 발화의 ID·문장·시작 및 종료 시간과 원본 오디오·회의록·전사 캐시·등록 목소리 파일은 설치 전 백업과 동일합니다. 설치 전 앱과 전체 라이브러리는 로컬 백업으로 보관했습니다.

- Mac 전체 단위 테스트: 534개 통과, 0개 실패, 5개 조건부 제외.
- iPhone 17 Pro 시뮬레이터 전체 단위 테스트: 399개 통과, 0개 실패, 5개 조건부 제외.
- Mac Release 빌드·서명 검증 및 Xcode 정적 분석 통과.
- 추가한 창 크기별 화면 전환 테스트와 기존 한국어 화면 렌더링 테스트 2개 통과.
- 변경된 화자·목소리 코드 최종 검토에서 추가 필수 수정 사항 없음.

실물 iPhone의 마이크 입력 및 모델 실행은 이번 검증에 포함되지 않았습니다. Mac의 일반 마우스 조작으로 분석·발화자 화면 전환을 확인했습니다. 별도로 자동화 도구가 분할 선택 컨트롤의 접근성 `press`를 직접 호출하면 AppKit의 반복된 크기 계산으로 앱이 종료되는 현상을 관찰했으며, 일반 마우스 클릭에서는 재현되지 않았습니다.
