# 회의록 웹 공유

Mac·iPhone·Windows에서 완성된 회의록을 같은 Cloudflare Worker로 게시합니다. 받는 사람은 앱 없이 웹 브라우저에서 읽을 수 있습니다.

## 공유 범위

- 공유 시점의 제목과 회의록 Markdown 본문을 사본으로 저장합니다.
- 원본 녹음, 전체 전사문, API 키는 공유 요청에 포함하지 않습니다.
- 링크를 가진 누구나 본문을 읽을 수 있습니다. 게시 전에 회의록 본문에 공개하지 않을 내용이 없는지 확인하세요.
- 링크는 생성 후 7일 동안 유효합니다. 회의록을 수정해도 기존 링크의 내용은 바뀌지 않습니다.
- 새 링크는 같은 녹음의 이전 링크를 종료합니다. 공유 해제도 가능합니다.
- 원본 녹음을 삭제하는 작업과 웹 공유 해제는 별개입니다. 공유를 중단하려면 먼저 공유 화면에서 해제하세요. 만료되면 자동으로 열람이 중단됩니다.
- 이미 받은 사람이 저장하거나 복사한 내용까지 회수할 수는 없습니다.

## 서버 설정

기존 Cloudflare Workers, D1, 비공개 R2를 그대로 사용합니다. 별도 웹 호스팅이나 공개 R2 버킷이 필요하지 않습니다. 관리 API는 기존 `SYNC_TOKEN`으로 인증합니다.

기존 설치는 `Cloudflare/migrations/0006_web_shares.sql`을 포함한 미적용 마이그레이션을 적용한 뒤 Worker를 배포해야 합니다. 새 설치는 전체 마이그레이션이 필요합니다. 저장소의 `wrangler.toml`은 템플릿이므로 실제 운영 D1 ID가 들어 있는 배포 설정을 사용하세요.

```sh
cd Cloudflare
npx wrangler d1 migrations apply note-taker-sync --remote
npx wrangler deploy
```

운영 설정을 별도 파일로 관리한다면 두 명령 모두 해당 설정을 `--config`로 지정하세요. 위 명령은 운영 데이터를 변경하고 코드를 배포합니다. 버킷의 공개 접근 설정은 켜지 않습니다. 서버 API 및 마이그레이션 세부 사항은 [Cloudflare 가이드](../Cloudflare/README.md)를 참고하세요.

## 앱 설정

### Mac·iPhone

기존 동기화 설정의 HTTPS 서버 주소와 토큰을 사용합니다. 자동 동기화를 켜지 않아도 공유할 수 있습니다. 회의록이 준비된 상태에서 웹 공유 화면을 열고 링크를 생성합니다. iPhone의 시스템 공유 기능으로 다른 앱에 링크를 전달할 수 있습니다.

### Windows

AI 설정의 웹 공유 항목에 같은 서버의 HTTPS 주소와 동기화 토큰을 저장합니다. OpenRouter 키는 공유 인증에 사용하지 않습니다. 공유 토큰은 Windows 계정에 연결된 DPAPI로 보호됩니다. Windows 녹음 파일을 Apple 동기화 형식으로 바꾸거나 전체 라이브러리를 올릴 필요가 없습니다.

## 링크 관리와 문제 해결

- 링크 원문은 생성 응답에서만 전달됩니다. 화면을 다시 열거나 다른 기기에서 접근한 경우 서버 상태를 확인해 해제하거나 새 링크를 만들 수 있습니다.
- 서버 미설정: 주소와 토큰을 저장하세요.
- 인증 실패: 기존 동기화 토큰과 서버 설정이 일치하는지 확인하세요.
- 서버가 공유 API를 지원하지 않음: Worker와 D1 마이그레이션 적용 여부를 확인하세요.
- 만료·해제된 링크: 상대방에게는 본문 없는 일반적인 찾을 수 없음 페이지가 표시됩니다.
- 네트워크 오류: 업로드가 서버에서 완료된 뒤 응답만 유실될 수도 있습니다. 공유 상태를 다시 확인하거나 공유를 해제하세요.

## 운영 범위

현재 저장소는 사용자 소유의 개인 Cloudflare 설치를 전제로 합니다. `SYNC_TOKEN`을 가진 앱은 해당 설치의 공유를 관리할 수 있습니다. 서로 모르는 여러 사용자를 하나의 토큰으로 연결하는 공개 서비스용 계정 체계는 아닙니다. 공개 앱에 운영 토큰을 내장하지 마세요.

공유 만료·해제는 즉시 접근 권한을 종료하지만 R2의 사본을 자동 삭제하지는 않습니다. 필요하면 공유 전용 객체 경로에 수명 주기 정리를 구성할 수 있습니다. 유효한 7일 링크를 먼저 삭제하지 않도록 보관 기간을 설정해야 합니다. 원본 녹음 경로에는 적용하지 마세요.

## 개발 검증

```sh
node --test Cloudflare/tests/*.test.mjs
```

로컬 Wrangler에서 D1 마이그레이션을 적용하고 서버를 실행한 뒤 HTTP 통합 검증을 실행할 수 있습니다. 아래 토큰은 로컬 테스트 설정과 일치해야 합니다. 검증 스크립트는 운영 서버에 잘못 실행하지 않도록 루프백 주소만 허용합니다.

```sh
SHARE_TEST_BASE=http://127.0.0.1:8799 \
SHARE_TEST_TOKEN=local-test-token \
node scripts/verify-web-sharing.mjs
```

검증은 임시 녹음 ID로 제목·회의록을 게시하고, 공개 HTML/보안 헤더 확인, 잘못된 요청 시 기존 공유 유지, 새 링크 생성 시 이전 링크 종료, 공유 해제와 재해제를 수행합니다. 마지막에 테스트 공유를 해제합니다.
